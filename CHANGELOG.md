# Changelog - ChombieWombie Tracklist Studio

## [v0.1.0] - 2026-04-27
### Added
- **Minimalist Studio Interface**: Single-page workspace with drag-and-drop track reordering.
- **Session Persistence**: Auto-saves workspace configuration and tracklist to local storage.
- **Smart CUE Parsing**: Handles `HH:MM:SS` exports and seamlessly injects timestamps.
- **Vibes Config UI**: Custom JSON-free interface to assign Vibe names to VS2 visual patches.
- **Export Suite**: One-click dropdown to copy YT chapters, download VS2 JSON, and auto-download 3-band MIDI rhythms.
- **Toast Notifications**: Non-intrusive animated UI acknowledgments for background processes.
