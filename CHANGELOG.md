# Changelog - ChombieWombie YT DJ

## [v1.2.0] - 2026-04-26
### Added
- **Dynamic Percentile Mapping**: Visual intensity thresholds now calculate based on the mix's relative energy range.
- **3-Minute Scene Refresh**: Automatic splitting of long visual scenes (180s limit).
- **Pro MIDI Extraction**: Added dynamic velocity mapping and 4000Hz treble sensitivity.
- **FileSystem Access API**: Native "Save As" dialogs for local protocol compatibility.
- **VS2 Preset Pools**: Integrated random rotation for Chill, Happy, and Intense patch categories.

## [v1.1.0] - 2026-04-26
### Added
- **Mix Lab Tab**: Interactive waveform and audio analysis engine.
- **Multi-Band MIDI**: Added Bass, Mid, and Treble rhythmic extraction.
- **VS2 Playlist Export**: Initial JSON export for visualizers.
- **Loading Spinners**: Improved UX during heavy audio decoding and analysis tasks.

## [v1.0.0] - 2026-04-26
### Added
- **CUE Converter**: Base logic to transform Rekordbox .cue files into YouTube chapter marks.
- **Dark Mode UI**: Sleek, DJ-focused interface with glassmorphism effects.
